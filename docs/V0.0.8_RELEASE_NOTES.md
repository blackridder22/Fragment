# Fragment 0.0.8 — Color palettes and SVG

## Added

- Automatic local color palettes for new images and SVGs, with up to six swatches.
- Click a swatch to copy HEX; use Find this color to search the current scope.
- A Color filter with presets, HEX, similarity tolerance and saved Smart Frame support.
- Background color indexing for existing Vaults, with progress and retry states.
- Static SVG file import and HTTP(S) browser image capture, preserving original bytes.
- SVG Fit/100/200/400% preview, pan, transparent/light/dark backgrounds and PNG Copy Image.
- Bounded Rust SVG rendering, cancelable work and cached high-resolution previews.
- Sequential native request scheduling so slow saves do not time out queued Frame requests.

- Expandable per-file import errors with Retry and Dismiss actions.
- Explicit native title-bar drag permission.

## Compatibility and limits

Schema 5 upgrades existing Vault metadata without modifying originals. An older
0.0.7 binary cannot open schema 5: rollback requires a pre-upgrade backup.
SVG support is static: scripts, animation, HTML/foreignObject, external resources,
DTD declarations, SVGZ and unsupported elements are rejected. Missing installed
fonts use a fallback and show a warning. The original retains its vector data;
only previews and clipboard images are rasterized. Browser capture currently
covers HTTP(S) image candidates, not arbitrary inline/data/blob SVG elements.
