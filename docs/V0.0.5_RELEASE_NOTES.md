# Fragment v0.0.5

## Frame Navigator

Fragment now exposes its existing Frame hierarchy as a Finder-grade navigator.
The Vault is the virtual root, while Inbox remains the undeletable system Frame
for captures and imports without an explicit destination.

- Create root Frames or Sub-frames from the navigator.
- Expand and collapse nested Frames with persisted state.
- Rename with F2, Enter, double-click, or the Frame context menu.
- Search Frames without losing the ancestor path.
- Pin frequently used Frames to Quick Access.
- Resize or collapse the navigator for more masonry space.
- Navigate the current hierarchy with breadcrumbs.
- Show direct and recursive Fragment counts (`direct/total`).
- Include or exclude Sub-frame Fragments from paginated browsing and selection.
- Drag Frames before, after, or inside another Frame with cycle protection.
- Drag selected Fragments onto any Frame row.
- Drag Frames or selected Fragments to Trash with the existing Undo behavior.

## Data safety

Frame reparent and reorder operations run in one SQLite transaction. The core
rejects moving Inbox, self-parenting, missing parents, and descendant cycles.
Recursive Fragment queries remain paginated and preserve existing global
asset-deduplication and per-Frame membership semantics.

## Verification

- Rust tests cover nested creation, sibling ordering, reparenting, protected
  Inbox, cycle rejection, and recursive Fragment scopes.
- Vitest covers tree flattening, search ancestry, breadcrumbs, recursive counts,
  drop placement, and persisted preference validation.
- Browser QA covers expand/collapse, Frame search, Quick Access, breadcrumbs,
  inline rename, recursive browsing, and narrow-window layout.
