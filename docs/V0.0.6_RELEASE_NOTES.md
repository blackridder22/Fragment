# Fragment v0.0.6

This beta deepens Fragment as a fast local-first visual retrieval tool while
preserving the established rail, glass surfaces, and canvas hierarchy.

## Frames and navigation

- Restores the original Fragment icon rail as the permanent visual spine.
- Adds a styled, resizable Frame tree with nested Sub-frames, pinning, drag
  reparenting, direct/recursive counts, and protected Inbox behavior.
- Keeps preview, Quick Preview, shortcut help, and other overlays constrained
  to the canvas so the Frame navigator never covers Fragment content.

## Retrieval and Smart Frames

- Adds SQLite-backed, pre-pagination filters for tags, media type, source,
  domain, dates, dimensions, orientation, file size, notes, title, site, and
  creator metadata.
- Adds dynamic Smart Frames that persist a typed filter query without copying
  Fragment memberships or image files.
- Adds schema version 4 with Smart Frame storage, revision triggers, and
  retrieval indexes.

## Inspector and browsing

- Adds a single-selection canvas inspector with editable title, notes, and
  tags; source and creator context; technical file metadata; and the approved
  Fragment actions.
- Adds Masonry, Grid, and List browsing modes with persistent density control.
- Adds Space-bar Quick Preview, right-click Fragment actions, and a discoverable
  keyboard shortcut guide.

No ratings, extracted color palette, or multi-selection metadata inspector were
added in this release.
