# UI Direction

Fragment is a visual inspiration vault. The MVP desktop UI must feel visual,
rounded, fast, calm, and macOS-native.

The primary surfaces are:

- Slim icon rail for Home, Frames, Capture, and Settings.
- Sticky top command bar with brand, search, Create Frame, Import, and status.
- Horizontal Frame chips.
- Visual Frame cards with thumbnail collages.
- Responsive masonry Fragment grid.
- Modal or sheet Fragment detail view.

Frames may have parent/child relationships in the data model, but nesting should
be represented with breadcrumbs, cards, chips, or shelves. Do not make a
collapsible file tree the primary navigation.

Avoid:

- IDE-like permanent inspectors.
- File explorer layouts.
- Admin dashboards or CRUD tables.
- Platform-specific capture vocabulary.

Use:

- Frame
- Fragment
- Vault
- Capture Mode
- Save Fragment
- Source
