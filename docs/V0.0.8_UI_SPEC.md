# v0.0.8 interaction specification

Specified before application UI changes. The existing v7 gallery, filter pills and focused overlay are the baseline. This document specifies states; it is not evidence that those states have passed native QA. Native screenshots and measurements belong in the QA report.

## Palette in the focused inspector

Place Colors after image metadata, before editable notes/tags. Keep the inspector width, padding, typography and existing editable controls. No palette queries per gallery card.

| State / action                  | Visible result and behavior                                                                                                                                                         |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pending / processing            | Compact “Extracting colors…” text; opening prioritizes this asset. Other controls remain usable.                                                                                    |
| Ready                           | One to six equal-size color buttons in coverage order. Tooltip and accessible name include HEX and rounded percentage. Transparent pixels do not appear as a background swatch.     |
| Click / Enter / Space on swatch | Copy uppercase HEX. Inline “Copied #RRGGBB” feedback, then restore selected color text. Clipboard failure gives a retryable message. Selection is independent of copying success.   |
| Find this color                 | Separate text/button action below the row, enabled when a swatch is selected. Apply default tolerance 80 to the current Frame/subframe/text/tag/source scope and close the preview. |
| Empty                           | “No visible colors” for fully transparent images. No invented swatches.                                                                                                             |
| Failed                          | “Colors could not be extracted” plus Retry. Repeated clicks do not create duplicate jobs.                                                                                           |
| Navigate to another Fragment    | Clear prior selection/feedback immediately; ignore responses for the previous asset. Existing arrows, title, note, tags and Trash behavior remain available.                        |

## Color filter

Add a Color pill alongside existing filters, with the existing popover surface, spacing and neutral focus styling. SVG joins the existing format choices.

| Action / state                             | Result                                                                                                                                                                   |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Open Color                                 | Focus HEX input; show six useful color presets, HEX input, tolerance slider (0–200), Apply and Clear.                                                                    |
| Enter `abc`, `#abc`, `AABBCC` or `#AABBCC` | Normalize to `#AABBCC` on Apply.                                                                                                                                         |
| Invalid HEX                                | Inline error; keep popover open and current results unchanged. Enter does not submit invalid input.                                                                      |
| Preset click                               | Set HEX draft; Apply commits. Slider has visible numeric value and accessible label.                                                                                     |
| Apply / Enter                              | Commit color plus tolerance, clear selection, reset page offset, close popover. Preserve other filters.                                                                  |
| Clear color                                | Remove only color predicate; preserve other filters.                                                                                                                     |
| Escape / outside click                     | Discard uncommitted draft, close popover, restore trigger focus. Escape within the popover does not dismiss an underlying focused preview.                               |
| Partial index                              | Show “Colors are still being extracted” with processed/total count; zero matches do not imply the entire Vault has been searched.                                        |
| Palette revision changes                   | Show “More color results available” with Refresh. Keep current cards, scroll and selection stable until Refresh. Do not append a page from a different palette revision. |
| Refresh                                    | Clear selection, restart pagination at the current color/filter scope and revision.                                                                                      |
| No matches                                 | Existing empty-results layout with color filter visible and a clear action.                                                                                              |

## SVG focused preview

Use the existing stage and inspector. Add a compact SVG-only toolbar inside the stage: Fit / 100% / 200% / 400%, and Transparent / Light / Dark background. Fit is default on every newly opened asset. Checkerboards are CSS backgrounds, never rendered into image bytes or palettes.

| Action / state    | Result                                                                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Open              | Show cached base PNG immediately; label SVG and nominal viewport dimensions without claiming a pixel-resolution ceiling.                   |
| Change zoom       | Change display geometry immediately. Debounce sharper PNG request 150 ms; keep current image visible with unobtrusive “Rendering…” status. |
| 100%              | One nominal viewport unit per CSS pixel; requested render tier accounts for device pixel ratio and the 4096-edge limit.                    |
| Pan               | Drag inside overflowing stage; normal inspector selection/editing remains unaffected. Fit resets pan.                                      |
| Background        | Change CSS stage background only; keep zoom and pan.                                                                                       |
| New asset / close | Cancel consumer request, reset pan/zoom/background; ignore late results. Keyboard navigation never waits for a render.                     |
| Render failure    | Keep last good PNG, show concise failure and Retry. Missing base PNG gets one automatic coalesced repair attempt, then explicit Retry.     |
| Missing font      | Inspector warning that an installed fallback was used. Original remains unchanged and revealable.                                          |
| Copy Image        | Copy PNG; verify by pasting into a native app. Reveal Original exposes `.svg`.                                                             |
| Escape            | Close preview using existing focus restoration. Toolbar buttons are keyboard reachable, with a neutral visible focus outline.              |

Respect reduced motion: no animated transitions are required for these states. Do not inject SVG markup or use SVG originals as WebView image fallbacks. SVG preview file URLs are bounded disk cache entries, not accumulated base64 strings.

## Review checklist

Capture native screenshots for palette pending/ready/empty/error/copied; color invalid/partial/empty/refresh; SVG Fit/zoom/background/loading/error/font substitution. Verify keyboard-only operation and existing gallery density, selection, edit/save, navigation and Trash preview. Browser fixture screenshots are separately labeled and cannot satisfy native verification.

## Import failure details

The existing compact import notice retains its aggregate count. When failures
exist, Show failed imports expands a bounded scroll area with each filename and
the backend's error message. Retry uses the existing single-item import queue;
Dismiss removes only that failed queue item, leaving saved Vault data intact.
A successful retry removes the failure through the existing completion event.
The disclosure is keyboard-operable and uses the current notice/theme tokens.
