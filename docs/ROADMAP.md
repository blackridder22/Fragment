# Roadmap

## MVP

- Visual desktop Vault.
- Default Inbox Frame.
- Frame create, rename, delete.
- Local image import.
- Thumbnail generation.
- Masonry Fragment grid.
- Fragment detail modal.
- Chrome Capture Mode overlay.
- Native host capture through URL-first save.

- Search polish.
- Tags in desktop UI.
- Duplicate UX.
- Better Source metadata display.
- Better Frame cover selection.
- Capture setup diagnostics.

## Later

- Canvas or moodboard view.
- Perceptual hashing.
- AI visual search.
- Optional encrypted sync.
- Safari extension.
- Mobile companion.
