# Fragment v0.0.7

This beta rebuilds the desktop experience around one consistent visual system
and the local-first Vault model.

## Highlights

- Rebuilt **Your Vault**, **Frames**, **Trash**, and **Settings** with a shared
  desktop layout, spacing system, controls, and interaction states.
- Turned Vault and Frames results into canvas-style workspaces: click previews
  a Frame, Shift-click adds or removes it from selection, and dragging on empty
  canvas creates a marquee selection.
- Added incremental pagination with automatic loading and a manual **Load more**
  fallback, so Vault, Frames, and Trash are no longer limited to the first page.
- Made Trash operations consistent: moving, restoring, undoing, and emptying
  Trash update the underlying memberships instead of creating duplicate UI
  copies. Empty Trash uses one native command and one atomic metadata
  transaction; asset paths are durably queued and file cleanup runs after the
  commit with retry support.
- Persisted desktop Settings, including appearance, reduced motion, refresh on
  focus, import destination, and delete retention preferences.
- Added best-effort Chrome native-host manifest setup when the macOS app starts,
  plus status reporting and the existing manual installer as a repair fallback.

## Interaction changes

- A normal Frame click opens preview instead of entering selection mode.
- Selection actions appear only after Shift-click or canvas marquee selection.
- Undo removes the same Trash membership it restores; it does not leave a
  duplicate behind.
- Exact duplicate assets continue to reuse stored files rather than creating a
  second original.
